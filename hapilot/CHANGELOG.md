# Changelog

## 0.1.14 — 2026-08-17

Простыня старых клавиатур в чате — две причины, обе устранены.

- «message is not modified» больше не считается ошибкой. Раньше нажатие кнопки,
  которая ничего не меняет (например «выкл» на уже выключенной лампе), приводило
  к удалению и переотправке сообщения: меню прыгало вниз чата и плодило копии.
  Теперь такой ответ Telegram просто игнорируется.
- Трекер последнего меню (`MENU_MSG`) поднят на модульный уровень и обновляется
  ВЕЗДЕ, где сообщение пересоздаётся (снимок камеры, аварийный путь правки).
  Раньше он хранил id уже удалённого сообщения, чистка удаляла «призрак»,
  а настоящее меню оставалось в чате навсегда.

Ограничение Telegram: сообщения старше 48 часов бот удалять не может — то, что
уже накопилось за этот срок, придётся убрать вручную.

## 0.1.13 — 2026-08-17

- Быстрые кнопки вкл/выкл теперь и в разделе «По типам» — в обеих раскладках
  (сгруппированной по комнатам и плоской с пагинацией). Раньше они были только
  в «По комнатам» и «Избранном».
- Возврат после нажатия учитывает, с какого экрана пришли: «по типам» перерисовывает
  свой список с тем же фильтром и страницей.

## 0.1.12 — 2026-08-17

- Быстрые кнопки вкл/выкл прямо в списках — без захода в карточку устройства.
  Строка устройства стала `[состояние + имя] [🟢] [⚪]`; имя по-прежнему открывает
  настройки (яркость, цвет, пресеты). Домены: light, switch, fan, input_boolean, siren.
- В списке комнат у каждой комнаты со светом — свои `[🟢] [⚪]`: гасит/включает весь
  свет комнаты, оставаясь на списке комнат (можно пройтись по нескольким подряд).
- Те же быстрые кнопки в «Избранном» — самый частый сценарий теперь в один тап от главной.
- После нажатия список перерисовывается на месте: сохраняются страница и фильтр
  по device_class, из списка не выбрасывает.
- Сенсоры и бинарные сенсоры быстрых кнопок не получают; медиа/климат/шторы —
  по-прежнему через карточку.

Тапов до результата: свет в комнате 5-6 → 2, конкретная лампа → 3, из избранного → 2.

## 0.1.11 — 2026-08-11

- Нижнее меню больше не залипает: `is_persistent=False` — работает родное сворачивание клавиатуры, из чата можно выйти в список чатов.
- Кнопка `⬇️ Свернуть меню` — прячет reply-клавиатуру (`ReplyKeyboardRemove`); вернуть — `/start`.

## 0.1.10 — 2026-08-11

- Гибридное меню: верхний уровень вынесен на **reply-клавиатуру** (persistent под полем ввода): `📍 Комнаты · 📋 Типы · 🚨 Алерты` + `⭐ Избранное` / `⚙ Настройки`. Вложенная навигация (комнаты→домены→entity, тумблеры, снимок, графики) и live-обновления остаются на inline (edit-in-place).
- Чистота чата: при тапе нижней кнопки удаляется предыдущее inline-меню и сам тап-текст — не копится «простыня», остаётся одно активное меню-сообщение.

## 0.1.9 — 2026-08-11

- Камера: при открытии сразу присылается кадр (без промежуточной кнопки «📸 Снимок»); на фото кнопки «🔄 Обновить» + «← Назад».
- Рефактор: логика снимка вынесена в общий хелпер `_send_camera_snapshot` (один путь для открытия камеры и для «Обновить»); для камеры не регистрируется live-экран.

## 0.1.0 — 2026-04-27

Первая версия.

- Автодискавери областей/устройств/entities из HA через WS API
- Меню «По комнатам» с группировкой по доменам
- Иконки для комнат (русские + английские названия)
- Авто-grid кнопок по длине текста
- Иконки и лейблы для бинарных датчиков (24 device_class)
- Раздел «Алерты»: активные тревоги, persistent notifications, недоступные устройства
- Quick actions: квитировать дым/протечку, перекрыть/открыть воду
- Camera snapshot в чат с заменой текущего сообщения
- Edit-mode для админа: настройка видимости устройств
- Whitelist user_ids
- Persistence в `/config/visibility.json`
