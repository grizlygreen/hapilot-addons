# Changelog

## 0.1.0 — 2026-04-27

Первая версия.

- Автодискавери областей/устройств/entities из HA через WS API
- Меню «По комнатам» с группировкой по доменам
- Иконки для комнат (русские + английские названия)
- Авто-grid кнопок по длине текста
- Иконки и лейблы для бинарных датчиков (24 device_class)
- Раздел «Алерты»: активные тревоги, persistent notifications, недоступные устройства
- Quick actions: квитировать дым/протечку, перекрыть/открыть воду
- Camera snapshot в чат с заменой текущего сообщения
- Edit-mode для админа: настройка видимости устройств
- Whitelist user_ids
- Persistence в `/config/visibility.json`

## 0.1.1 — 2026-04-27

- Fix: admin_user_ids теперь неявно allowed (раньше нужно было дублировать id в allowed_user_ids)

## 0.1.2 — 2026-04-27

- UX: allowed_user_ids/admin_user_ids теперь строки с запятой (`27059994` или `27059994,123456`)
  вместо list — исправляет случай когда пользователь вводит число в поле, не понимая что это список

## 0.1.3 — 2026-04-27

- Опция `proxy_url` для api.telegram.org (HTTP/HTTPS/SOCKS5)
  Полезно если у провайдера заблокирован Telegram (РФ и т.д.)
- Зависимость aiohttp-socks для поддержки SOCKS5

## 0.1.4 — 2026-04-27

- Light: цветовая температура (тёплый/дневной/холодный) — для ламп с color_temp
- Light: 8 базовых RGB цветов (красный/оранжевый/жёлтый/зелёный/синий/фиолетовый/розовый/белый) — для RGB ламп
- Раздел «📋 По типам» — все entities одного домена сгруппированы по комнатам
- noop-handler для разделителей-заголовков групп

## 0.1.6 — 2026-04-28

- Pre-built образы через GitHub Actions → ghcr.io/grizlygreen/{arch}-hapilot
- Установка add-on больше не требует pip + DNS-резолва внутри docker build
  (на части HAOS-инстансов резолв падал с "Name does not resolve"
  при попытке тянуть aiogram с files.pythonhosted.org)
- Установка ускорилась с ~3 мин до ~10 сек (просто image pull)

## 0.1.5 — 2026-04-28

- Массовые действия в комнате: «🟢 Все вкл / ⚪ Все выкл» для light/switch/fan
  с counts по числу выключенных/включенных
- Избранное (⭐): закрепление entity в корне для быстрого доступа,
  храним в `/config/favorites.json`, кнопка ⭐/✩ в карточке
- Live-обновление через HA WebSocket `subscribe_events` —
  карточки и списки entity (по комнатам, по типам, избранное)
  пересобираются автоматически при изменении состояния в HA
  (debounce 1 сек, TTL экрана 10 мин, max 50 экранов)
- Климат: HVAC-режимы (off/heat/cool/auto/dry/fan_only),
  target_temperature ±0.5/±1°, target_temp_low/high для диапазонных
  термостатов, preset_modes, fan_modes
- Humidifier: target humidity ±5%, set_mode
- Карточка климата показывает current/target температуру, диапазон,
  hvac_action, fan_mode
- Sensor/binary_sensor разбиваются на подменю по device_class:
  • в «По типам» — всегда
  • в комнатах — если >10 entity (порог настраиваемый)
- Округление числовых state до 2 знаков (или suggested_display_precision)
  и trim trailing zeros — больше нет «1013.250000000» у атмосферного давления
- Двойная навигация в каждом меню глубже корня: «← Назад» + «🏠 Меню»
- Smart-back из подменю классов и из карточки entity
- Cleanup: удалён мёртвый cb_back handler с битой сигнатурой
